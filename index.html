How to Use This Trainer

Game Overview

This game teaches you to decompose just intonation ratios into prime factorizations using keystroke shortcuts.

For example, to create 6/5, you would press the keys for 3/2 and 4/5 (since 3/2 × 4/5 = 6/5).

Controls

  • Number keys (1234567890): Prime ratios (2/1, 3/2, 5/4, etc.)
  • Letter keys (qwertyuiop): Reciprocals (1/2, 2/3, 4/5, etc.)
  • Backspace: Clear current answer
  • Order doesn't matter: 3/2 then 4/5 is the same as 4/5 then 3/2

Default Key Mappings

Prime ratios (suggested number keys):

  • 2/1 → 1, 3/2 → 2, 5/4 → 3, 7/4 → 4, 11/8 → 5
  • 13/8 → 6, 17/16 → 7, 19/16 → 8, 23/16 → 9, 29/16 → 0

Reciprocal ratios (suggested letter keys):

  • 1/2 → q, 2/3 → w, 4/5 → e, 4/7 → r, 8/11 → t
  • 8/13 → y, 16/17 → u, 16/19 → i, 16/23 → o, 16/29 → p

You can customize these mappings in the Configure Mappings menu.

Level Progression

  • Complexity = numerator × denominator
  • Higher complexity means more challenging decompositions
  • All intervals use numbers ≤ 30
  • All intervals are octave-reduced (between 1/1 and 2/1)
