The AHK macro — what it does

midi_interval_macro.ahk is an AutoHotkey v1 script that intercepts keypresses while your DAW is active and translates them into sequences of arrow keys, copy, and paste commands — letting you compose JI harmony at typing speed directly in a piano roll.

The entire workflow is built on three operations:

1. Copy + Paste — duplicating a note to a new position

The Copy+Paste key (default Tab in the qwerrttY preset) sends Ctrl+C then Ctrl+V in a single keypress. In a piano roll this duplicates the selected note in place, giving you a second note you can then shift to any pitch. You copy a note, paste it, then move it — that's how you build chords.

2. Interval shift — moving a note by a JI ratio

Each macro slot holds a JI ratio (e.g. 3/2). When you press that slot's hotkey, the script converts the ratio to the nearest EDO step count (steps = round(1200 × log₂(ratio) ÷ stepSize)) and sends that many Up or Down arrow keypresses to the DAW. A selected note moves by exactly that interval.

3. Paste — returning to the copy position

The Paste key (default ` in the qwerrttY preset) sends Ctrl+V alone. Because the DAW's clipboard still holds the originally copied note, pressing Paste again drops another copy of that note at its original pitch — it brings you back to where you started. This is how you add multiple notes to a chord: Copy+Paste → shift to first interval → Paste → shift to second interval → Paste → and so on.

The full chord workflow in a DAW:
1. Select the root note.
2. Press Tab (Copy+Paste) — a copy of the root now sits on top of it, selected.
3. Press the interval key (e.g. 3 for 5/4) — the copy moves up a major third.
4. Press ` (Paste) — another copy of the root is pasted, selected.
5. Press 2 (for 3/2) — it moves up a perfect fifth.
You've built a JI major chord in 5 keystrokes without touching the mouse.

Additional controls

  • Toggle (NumpadEnter / Ctrl+CapsLock depending on preset) — enables/disables all macro hotkeys. Hotkeys start disabled; a tooltip confirms state.
  • Undo (Numpad−) — sends Ctrl+Z exactly as many times as arrow keys were sent in the last action, perfectly reversing it.
  • Redo (Numpad+) — re-applies the last undone action.
  • Arrow remaps (a / s / d / f) — send Left / Up / Down / Right arrow keys, for navigating the piano roll without moving your hand.
  • Ctrl+` — opens the configuration GUI from anywhere.
  • Modifier passthrough — holding Ctrl, Alt, or Win while pressing a hotkey passes the original keypress through unchanged, so DAW shortcuts (Ctrl+Z, Ctrl+S, etc.) still work.

Sleep Delay

Some DAWs can't process a rapid burst of arrow keys at 0 ms intervals. If notes land on the wrong pitch, open Ctrl+` and increase Sleep Delay in small increments (try 5–20 ms) until it's reliable.

How this trainer maps to the macro workflow

Every exercise in this trainer is directly simulating what you'll do inside a DAW using the macro. The mapping is intentional:

In the trainerIn the DAW with the macro
Press ratio keys to build an interval Press interval hotkeys to shift a pasted note to the right pitch
Press ` (submit / Enter Note) Press ` (Paste) — drops the next copy of the root back at base pitch
Navigate the grid to the target cell Use arrow remaps (a/s/d/f) to navigate the piano roll or move between notes
Press Tab (capture target in grid modes) Press Tab (Copy+Paste) — duplicates the selected note to start building a new chord tone

This means the grid modes are the most realistic simulation: navigate to a target (like moving to a note in the roll), press Tab to capture it (like Copy+Paste), then immediately enter the chord (like shifting the copy to the right interval and pasting more copies for remaining notes).

Why train this way? The bottleneck in JI piano-roll composition isn't knowing the theory — it's the time cost of mentally converting an interval to steps and navigating there. This trainer burns those conversions into finger memory so the whole workflow becomes as fast as typing.

What is Just Intonation?

In just intonation every musical interval is expressed as a ratio of two whole numbers. The simpler the ratio, the more consonant the sound:

RatioInterval nameFeeling
2/1OctaveSame pitch, doubled frequency
3/2Perfect fifthOpen, stable, powerful
4/3Perfect fourthOpen, slightly ambiguous
5/4Major thirdBright, sweet — smoother than 12-TET
6/5Minor thirdDark, melancholy — also smoother than 12-TET
7/4Harmonic seventhBluesy, "barbershop" sound, no 12-TET equivalent
11/8Undecimal tritoneNeutral, mysterious
13/8Tridecimal neutral sixthExotic, otherworldly

Chords are stacks of these ratios from a common root — for example the JI major chord 4:5:6 uses the intervals 1/1, 5/4, and 3/2.

EDO note: The macro converts ratios to the nearest EDO step. The default preset uses 37-EDO, which represents 5- and 7-limit JI much more accurately than 12-TET. The qwerrttY preset uses 12-EDO for standard chromatic work. Use whatever EDO your DAW project is set to.

The core keyboard skill

Almost every JI interval can be built by multiplying a small set of prime ratios together. The trainer teaches you to decompose any ratio into keypresses the same way you'd factorise a number.

Example: to build 15/8 (major seventh):

  • 15/8 = 3/2 × 5/4
  • Press the key for 3/2, then the key for 5/4
  • Order doesn't matter — the trainer multiplies them together

Example: to build 9/5 (minor seventh):

  • 9/5 = 3/2 × 3/2 × 4/5 — two fifths up, one major third down
  • Press 3/2 twice and 4/5 (the downward key for 5/4) once
Tip: The trainer reduces your composition and compares it to the target, so you can press keys in any order.

Recommended training order

Follow these steps roughly in sequence. Each one builds on the previous.

  1. Build key-to-ratio muscle memory (Interval Mode, early levels) Start with the first few levels covering 2/1, 3/2, 5/4, 6/5, and 4/3. The adaptive system will keep drilling whichever intervals you're slow on. Aim for a consistent sub-3-second response time before unlocking the next level. This step is pure finger memory — you want the key for 3/2 to feel as automatic as typing a letter.
  2. Practise compound intervals (Interval Mode, higher levels) Once single prime ratios are automatic, the trainer introduces intervals that require two or three keypresses — like 15/8 (= 3/2 × 5/4) or 9/5 (= 3/2 × 3/2 × 4/5). This is where decomposition thinking begins. Complexity = numerator × denominator; work through levels gradually.
  3. Learn JI triads (Chord Mode, Level 1–4) Switch to Chord Mode. The first levels cover Major, Minor, Diminished, Augmented, Sus2, Sus4, Subminor, and Supermajor triads. You'll build each chord note-by-note from the root using the same ratio keys. Enable "Include Inversions" once the root-position voicings feel comfortable.
  4. Add seventh and sixth chords (Chord Mode, Level 5+) Higher levels introduce Dominant 7th, Major 7th, Minor 7th, Harmonic 7th, and the septimal/supermajor variants. The 7/4 key becomes essential here. Use "Random Starting Note" once root-position chords feel fast.
  5. Set up the AHK macro and practise in your DAW Configure the macro to match your chord-trainer key layout (or use the qwerrttY preset which matches the trainer defaults). Open a blank project, place a note in the piano roll, and practise the Tab → shift → ` → shift workflow until it's fluid.
  6. Grid + Chord mode — fluency under navigation pressure Now combine movement and chord entry. In Chords + Grid Mode you navigate a 2D grid to a target cell (simulating moving to a note in the roll), press Tab to capture it (simulating Copy+Paste), then immediately enter the chord.
  7. Onslaught Mode — maintain speed under time pressure Multiple targets appear and fade. Treat this as a stress test: if you hesitate on any chord, it will show up. Use it to identify which chords still need drilling in the dedicated modes.

The four game modes

📊
Adaptive Interval Mode

Single intervals presented one at a time. Build them from prime-ratio keys. Adaptive difficulty: slow intervals are repeated more often. Unlocks new intervals as you master existing ones.

🎵
Adaptive Chord Mode

Full chords built note-by-note from the root. Progress through triads to seventh and sixth chords. Includes inversions and random starting note options.

🎯🎵
Chords + Grid Movement

Navigate a 2D grid to a target cell, then enter the chord. Simulates the DAW workflow of moving to a note position and entering harmony. Timer tracks overall fluency.

⚡
Onslaught Mode

Multiple chord targets appear on the grid simultaneously and fade away on a timer. Solve as many as possible. Spawn rate accelerates as you succeed — a real-time stress test of combined navigation and chord fluency.

Interval Mode in depth

How a round works

  1. A target interval is displayed (e.g. 15/8).
  2. Press the ratio keys that multiply to that target — e.g. 2 (3/2) then 3 (5/4) = 15/8.
  3. Press ` (or your configured submit key) to confirm.
  4. Green flash = correct; red = wrong answer shown, then repeat.

Adaptive progression

The trainer maintains a rolling average of your response time for each interval. When your average drops below the Mastery Time Threshold (default 3.5s) across enough attempts, that interval is marked mastered and a new one is unlocked. Mastered intervals still appear occasionally to prevent forgetting.

Display modes

Use Rotate: All Three once you're comfortable — each question cycles between showing you the fraction, cents value, or name. This prevents you from relying on a single representation and builds the full mental map between all three.

Ear training mode

Tick Ear training only (hide target interval) to hear the interval played and identify it purely by sound. This is advanced — only attempt it once the visual mode is fast.

Chord Mode in depth

How a round works

  1. A target chord is displayed with its harmonic notation (e.g. 4:5:6 — Major) and the individual intervals above the root.
  2. Build the chord note by note: press the key for each interval from the root, in any order.
  3. Each correctly placed note lights up green on the piano roll display.
  4. When all notes are placed correctly the chord auto-submits.

Inversions

When inversions are enabled, the chord may be presented starting from its 3rd or 5th rather than the root. The harmonic notation updates to show the new bass note. For example, the first inversion of 4:5:6 (Major) is written 5:6:8.

Random Starting Note

Normally chords are built upward from the root. With this option enabled the root may be placed anywhere, so some intervals will require downward ratio keys. For example, a Major chord built from the 5th requires pressing 4/5 (downward major third) and 2/3 (downward fifth) to reach the other notes.

Level progression: Each level unlocks one additional base chord type. All inversions of a chord type are unlocked together. The level display is clickable — click it to see exactly which chords are currently active.

Grid & Onslaught modes

Grid navigation controls

Default grid movement keys (configurable in Configure Hotkeys):

  • a = move left
  • s = move up
  • d = move down
  • f = move right
  • Tab = capture / select target cell (maps to Copy+Paste in the macro)
Ergonomics tip: These defaults match both the macro's arrow-remap keys and the macro's Copy+Paste key (Tab). Training with these settings means the exact same hand movements carry over to the DAW.

Chords + Grid Mode

A red target appears somewhere on the grid. Navigate to it and press Tab to capture it — just as you'd press Tab to Copy+Paste a note in the DAW. The display switches to chord entry: build the chord shown, then the next target spawns.

Onslaught Mode

Multiple targets appear at once and each has a fade timer (default 15 s). Walk to a target, capture it, enter the chord. Each correct note slightly accelerates the spawn rate; each expired target penalises the spawn timer. Configure the chord pool by clicking preset level cards or writing custom chords in the format: 

[1/1, 5/4, 3/2] : Major
[1/1, 6/5, 3/2] : Minor
[4, 5, 6, 7] : Harmonic 7th   ← harmonic integers also accepted

Macro layout & ergonomics

The config ships with two complementary presets. Both are starting points — every key is fully reassignable in the config GUI (Ctrl+`).

Default preset — numpad, 37-EDO

Designed for one-handed use on a numpad while the other hand stays on the mouse. Intervals are grouped in adjacent pairs (up/down for the same ratio sit next to each other) so you can roll between them without repositioning:

  • 3/2 up/down → Num8 / Num9 (side by side, middle row)
  • 5/4 up/down → Num5 / Num6 (side by side, centre)
  • 7/4 up/down → Num2 / Num3 (side by side, lower row)
  • 11/8 up/down → Num0 / Num. (bottom row)
  • 2/1 up/down → NumLock / Num7 (top row, less frequent)
  • 13/8 up/down → NumDiv / NumMult (top operators)
  • Undo/Redo → Num− / Num+ (right column)
  • Toggle → NumpadEnter

EDO is set to 37, giving accurate representation of 5-limit and 7-limit JI intervals.

qwerrttY preset — keyboard row, 12-EDO

Designed to match the trainer's default key layout, so training sessions transfer directly to DAW sessions. The number row covers upward ratios, the letter row below covers their reciprocals. Navigation and copy/paste are on the left hand:

  • Upward ratios → 1–7 (2/1, 3/2, 5/4, 7/4, 11/8, 13/8, 17/16)
  • Downward ratios → q–u (reciprocals of above)
  • Copy+Paste → Tab
  • Paste → `
  • Navigation → a / s / d / f
  • Toggle → Ctrl+CapsLock

Principles for customising to your hand

  1. Group your most-used intervals together. 3/2 and 5/4 are used constantly. Put them where your fingers rest naturally — ideally adjacent so you can roll between them without repositioning.
  2. Keep up/down for the same interval spatially related. Side-by-side or top/bottom both work. The default numpad preset puts each pair as left/right neighbours on the same row.
  3. Disable intervals you don't compose with. Slot 7 is disabled in the default preset. Disable any slot to prevent accidental triggers.
  4. Match the trainer key layout to the macro layout. The closer the trainer's ratio keys are to the macro hotkeys, the more directly drill sessions transfer to DAW sessions. The qwerrttY preset does this by design.
  5. Use presets for different EDOs or styles. Save a 37-EDO preset for JI work and a 12-EDO preset for standard chromatic work. Switch instantly from the config GUI.
  6. Tune Sleep Delay to your DAW. Test by pressing a large interval (e.g. 2/1 = 37 steps in 37-EDO) on a selected note. If it doesn't land exactly an octave up, increase Sleep Delay by 5 ms increments.

FAQ

Progress keeps getting reset — how do I recover?

Progress is saved to your browser's localStorage. Clearing browser data, using private/incognito mode, or switching browsers will lose it. Use the Resume from Specific Level section on the settings page: enter the number of intervals (or base chords) you had unlocked to jump straight back.

The macro fired the wrong number of steps — notes are off.

This is almost always a Sleep Delay issue. Some DAWs queue rapid arrow-key events unreliably at 0 ms. Open Ctrl+` → increase Sleep Delay to 5–15 ms → Save → test again.

The macro hotkeys interfere with typing when I don't want them to.

The macro starts suspended (hotkeys disabled). Press the Toggle key to activate them, and press it again to disable. A tooltip confirms the state. Only enable the macro when you're actively using it in the DAW.

How do I use the macro with a DAW that uses semitone arrows by default?

Most DAWs move selected MIDI notes by one semitone per Up/Down arrow. Set EDO to 12 in the macro config (use the qwerrttY preset as a starting point). For microtonal DAWs, use the matching EDO and ensure the DAW step size matches one EDO step per arrow press.

Can I add custom intervals or chords the trainer doesn't include?

For Onslaught Mode yes — use the custom chord text editor on the settings page. For the Adaptive modes, chords are defined in data/chordTypes.js. To add a new chord type, add an entry to BASE_CHORD_TYPES and CHORD_NAMES in that file.

What EDO is best for JI composition?

For 5-limit JI (primes 2, 3, 5): 31-EDO is excellent. For 7-limit (adding 7): 31 or 72-EDO. For 11-limit (adding 11): 72-EDO covers it very well. The default preset uses 37-EDO as a good practical balance across 5- and 7-limit intervals. 12-TET approximates 7/4 and 11/8 quite coarsely.

I find the decomposition confusing. Any tips?

Think of it like mental arithmetic with prime factors:

  • Factor numerator and denominator separately, then assign each factor to a key.
  • Example: 15/8 = (3 × 5) / (2³) = 3/2 × 5/4. Press those two keys.
  • Example: 9/8 = 3² / 2³ = 3/2 × 3/2 × 1/2. Press 3/2 twice, then 1/2 once.
  • Drill the single-prime intervals until they're instant — compound intervals are trivially fast once the primes are automatic.
